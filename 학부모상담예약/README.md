# 학부모 상담 예약 웹앱

구글 시트 + Apps Script로 만든 상담 신청 페이지입니다. 별도 서버나 비용 없이 구글 계정 하나로 운영합니다.

## 할 수 있는 것

| 누가 | 무엇을 |
|---|---|
| 학부모 | 링크로 들어와 날짜 → 시간 → 아이 이름·보호자 입력 후 신청. 이미 찬 시간은 "신청 완료"로 막혀 있음. 확인번호 4자리로 내 예약 확인·취소 |
| 관리자(나) | 구글 시트 "예약현황"에서 이름 확인. 또는 웹앱 맨 아래 **관리자** → 관리자 코드 입력 → 명단 보기 |
| 공동 관리자(동료 교사) | 스프레드시트를 **편집자**로 공유받아 "설정"(제목·반 이름·담임 등)과 "일정"(날짜·시간)을 바로 수정 |

- **중복 방지**: 신청할 때 서버가 잠금(LockService)을 걸고 다시 확인하기 때문에, 두 사람이 같은 시간을 동시에 눌러도 한 명만 접수됩니다.
- **아이당 1건**: 같은 아이 이름으로 두 번 신청할 수 없습니다(바꾸려면 취소 후 재신청).
- **학부모는 다른 사람 이름을 볼 수 없습니다.** 화면에는 "신청 완료" 여부만 나옵니다.

## 설치 (처음 한 번, 약 10분)

1. [sheets.new](https://sheets.new)에서 새 스프레드시트를 만들고, 이름을 예를 들어 `햇살반 상담예약`으로 짓습니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 파일 `Code.gs`의 내용을 지우고 이 폴더의 `Code.gs` 내용을 붙여넣습니다.
4. 왼쪽 **파일 +** → **HTML** → 이름을 `Index`로 지정(대소문자 정확히)한 뒤 `Index.html` 내용을 붙여넣습니다.
5. 저장 후 위쪽 함수 선택에서 `setup`을 고르고 **실행**을 누릅니다. 권한 요청이 나오면 내 계정으로 허용합니다.
   - "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 누릅니다. 내가 만든 스크립트라서 나오는 경고입니다.
6. 시트로 돌아가면 `설정`, `일정`, `예약현황`, `보관` 탭이 생겨 있습니다. `설정`과 `일정`을 반에 맞게 고칩니다.
7. Apps Script에서 **배포 → 새 배포 → 유형: 웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
8. 나온 **웹 앱 URL**을 학부모 단톡방이나 알림장에 공유합니다.

> **관리자 코드**는 `설정` 시트 B9 칸에 무작위 6자리로 들어가 있습니다. 학부모에게는 절대 알려주지 마세요.

## 계속 쓰는 법

- **날짜·시간 바꾸기**: `일정` 시트에서 한 줄에 날짜 하나, 시간은 쉼표로 구분합니다 (`2026-11-03` | `14:00, 14:30, 15:00`). 저장하는 즉시 웹앱에 반영되고 재배포는 필요 없습니다. 지난 시간은 자동으로 숨겨집니다.
- **반 이름·제목 바꾸기**: `설정` 시트에서 고치면 바로 반영됩니다.
- **신청 잠시 막기**: `설정`에서 `예약 받기`를 `아니오`로 바꿉니다.
- **새 학기·새 상담 기간**: 시트 메뉴 **상담예약 → 지난 예약 보관하기**를 누르면 기존 신청이 `보관` 탭으로 옮겨지고 `예약현황`이 비워집니다. 같은 링크를 계속 쓸 수 있습니다.
- **관리자가 대신 취소**: `예약현황`에서 해당 줄의 `상태`를 `취소`로 바꿉니다(행을 지우지 말고 상태만 바꾸는 것을 권장).
- **동료 교사와 함께 관리**: 스프레드시트 **공유 → 편집자**로 추가합니다. Apps Script 코드를 고친 경우에만 **배포 관리 → 수정 → 새 버전**이 필요합니다.
- **다른 반에서도 쓰기**: 스프레드시트를 **사본 만들기**하면 스크립트도 함께 복사됩니다. 사본에서 `setup` 없이 시트만 고친 뒤 7번(배포)부터 하면 됩니다.

## 알아둘 점

- 웹앱 상단에 "Google Apps Script 사용자가 만든 애플리케이션입니다"라는 구글 안내 문구가 표시됩니다. 개인 구글 계정으로 배포하면 없앨 수 없습니다.
- 학부모 본인 확인은 "아이 이름 + 확인번호"뿐입니다. 로그인 없이 쓰는 대신 생기는 한계라서, 장난 신청은 관리자가 시트에서 취소해야 합니다.
- 개인정보는 꼭 필요한 만큼만 받으세요. 기본값으로 연락처는 받지 않습니다. 상담 기간이 끝나면 `보관` 탭의 내역을 원 규정에 맞춰 지우는 것을 권장합니다.
