# 학부모 상담 예약 웹앱

구글 시트 + Apps Script로 만든 상담 신청 페이지입니다. **원 전체가 시트 하나, 링크 하나로 함께 씁니다.** 별도 서버나 비용은 들지 않습니다.

## 누가 무엇을 하나

| 누가 | 어디서 | 무엇을 |
|---|---|---|
| 학부모 | 웹앱 링크 | 반 → 날짜 → 시간 → 아이 이름·보호자 입력 후 신청. 찬 시간은 "신청 완료"로 막혀 있음. 확인번호 4자리로 내 예약 확인·취소 |
| 담임 선생님 | 구글 시트(편집자) | "일정"과 "명단"에서 **자기 반 줄**을 직접 고침. 저장하면 웹앱에 바로 반영 |
| 담임 선생님 (휴대폰) | 웹앱 맨 아래 **관리자** | **반 관리자 코드**를 넣으면 **우리 반 신청자만** 보임. 아직 신청하지 않은 아이 목록도 함께 보임 |
| 원장님·행정 | 웹앱 / 시트 | **전체 관리자 코드**를 넣으면 모든 반 명단이 보임 |

### 보호 장치
- **같은 시간 중복 신청 불가**: 신청할 때 서버가 잠금을 걸고 다시 확인합니다. 두 사람이 같은 시간을 동시에 눌러도 한 명만 접수됩니다.
- **아이당 1건**: 같은 반, 같은 이름으로 두 번 신청할 수 없습니다. 바꾸려면 취소한 뒤 다시 신청합니다.
- **명단 확인**: "명단" 시트에 있는 아이 이름으로만 신청할 수 있습니다. 띄어쓰기는 무시합니다. 명단이 비어 있는 반은 이름을 확인하지 않습니다.
- **학부모는 다른 사람 이름을 볼 수 없습니다.** 화면에는 "신청 완료" 여부만 나옵니다.

## 설치 (원에서 한 사람이 한 번, 약 10분)

1. [sheets.new](https://sheets.new)에서 새 스프레드시트를 만듭니다. 이름은 예를 들어 `OO어린이집 상담예약`으로 합니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 파일 `Code.gs`의 내용을 지우고 이 폴더의 `Code.gs`를 붙여넣습니다.
4. 왼쪽 **파일 +** → **HTML** → 이름을 `Index`로 짓고(대소문자 정확히) `Index.html` 내용을 붙여넣습니다.
5. 저장한 뒤 위쪽 함수 목록에서 `setup`을 고르고 **실행**을 누릅니다. 권한 요청이 뜨면 허용합니다.
   - "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 누릅니다. 내가 만든 스크립트라서 나오는 경고입니다.
6. 시트에 `설정`, `반`, `일정`, `명단`, `예약현황`, `보관` 탭이 생깁니다. 예시로 들어간 햇살반과 꽃잎반을 우리 원의 반으로 바꿉니다.
7. Apps Script에서 **배포 → 새 배포 → 유형: 웹 앱**을 고르고 아래처럼 설정합니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
8. 화면에 나온 **웹 앱 URL**이 학부모용 링크입니다.
9. 시트 오른쪽 위 **공유**에서 담임 선생님들을 **편집자**로 추가합니다.

## 링크 나눠 주기

- **원 전체 링크**: 웹 앱 URL을 그대로 보내면 학부모가 반을 직접 고릅니다.
- **반별 링크(권장)**: URL 끝에 `?반=햇살반`을 붙이면 그 반이 미리 선택된 채로 열립니다. 반 단톡방에는 이 링크를 보내세요.
  예: `https://script.google.com/macros/s/XXXX/exec?반=햇살반`

## 계속 쓰는 법

- **반 추가·담임 변경**: `반` 시트에 한 줄을 추가합니다. 반 관리자 코드는 숫자 6자리를 아무거나 직접 넣으면 됩니다.
- **날짜·시간**: `일정` 시트에 `반 | 날짜 | 시간` 순서로 적습니다. 시간은 쉼표로 구분합니다(예: `햇살반 | 2026-11-03 | 14:00, 14:30, 15:00`). 지난 시간은 자동으로 숨겨집니다.
- **반 아이 명단**: `명단` 시트에 `반 | 아이 이름`을 한 줄에 한 명씩 적습니다. 학기 초에 한 번만 넣으면 됩니다.
- **신청 잠시 멈추기**: `설정`에서 `예약 받기`를 `아니오`로 바꿉니다.
- **새 상담 기간**: 시트 메뉴 **상담예약 → 지난 예약 보관하기**를 누르면 기존 신청이 `보관` 탭으로 옮겨집니다. **링크는 그대로** 다시 쓸 수 있습니다.
- **관리자가 대신 취소**: `예약현황`에서 그 줄의 `상태`를 `취소`로 바꿉니다. 행을 지우지 말고 상태만 바꾸세요.
- 시트를 고칠 때는 재배포가 필요 없습니다. Apps Script **코드**를 바꾼 경우에만 **배포 관리 → 수정 → 새 버전**을 하세요.

## 다른 원에 나눠 주기 (템플릿 링크)

1. 설치를 마친 시트에서 `예약현황`, `보관`, `명단`을 비웁니다. 관리자 코드도 바꿔 둡니다.
2. 공유 설정을 **링크가 있는 모든 사용자 – 뷰어**로 바꿉니다.
3. 시트 주소 끝의 `/edit...`를 `/copy`로 바꿔서 나눠 줍니다.
   예: `https://docs.google.com/spreadsheets/d/시트ID/copy`
4. 받은 사람이 링크를 열면 **자기 드라이브에 사본**이 생깁니다. 사본에는 코드도 함께 들어 있습니다. 받은 사람은 위 설치 7~9단계(배포)만 하면 됩니다.

이렇게 하면 원마다 데이터가 따로 저장되므로 다른 원의 학부모 정보가 섞이지 않습니다.

## 알아둘 점

- **시트 편집자는 모든 반의 신청 내역을 볼 수 있습니다.** 반 관리자 코드는 웹앱 화면만 반별로 나눠 줍니다. 반 사이에도 명단을 엄격히 분리해야 한다면 반마다 시트를 따로 만드세요(위 템플릿 방식).
- 로그인이 없기 때문에, 명단에 있는 다른 아이 이름을 아는 사람이 대신 신청하는 것까지는 막지 못합니다. 이런 신청은 관리자가 시트에서 취소합니다.
- 웹앱 상단에 구글이 "Google Apps Script 사용자가 만든 애플리케이션"이라는 안내를 띄웁니다. 개인 계정으로 배포하면 없앨 수 없습니다.
- 개인정보는 꼭 필요한 만큼만 받습니다. 연락처는 기본으로 받지 않습니다. 상담 기간이 끝나면 `보관` 탭을 원 규정에 맞게 정리하세요.
