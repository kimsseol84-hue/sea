# 바다생물 잡기 모션게임

Vercel 배포용 React + Vite 프로젝트입니다.

## 배포 방법

1. 이 ZIP 파일을 압축 해제합니다.
2. GitHub 새 저장소를 만듭니다.
3. 압축 해제한 폴더 안의 파일 전체를 GitHub에 업로드합니다.
4. Vercel에서 Add New Project를 누릅니다.
5. GitHub 저장소를 선택하고 Deploy를 누릅니다.
6. 생성된 https:// 주소로 휴대폰/패드에서 접속합니다.
7. 카메라 권한을 허용합니다.

## 기능

- 손 인식 모드
- 터치 모드
- 카메라 화면 위에 바다생물만 나타나는 AR 느낌
- 점수
- 30초 제한 시간

카메라 기능은 보안 정책상 https:// 또는 localhost 환경에서만 안정적으로 작동합니다.
